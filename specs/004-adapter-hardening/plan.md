# Implementation Plan: Adapter Hardening

**Branch**: `004-adapter-hardening` | **Date**: 2026-07-25 | **Spec**: [[spec]] — `specs/004-adapter-hardening/spec.md`

**Input**: Feature specification from `specs/004-adapter-hardening/spec.md`

## Summary

Three changes to the live adapter: prune backups to a declared limit, verify the composed output carries
the source content rather than only valid structure, and add a lint group that skips loudly when the
linter is absent. Nothing on the success path may change.

## Technical Context

**Primary Dependencies**: none new. `shellcheck` is optional by design — the lint group must work without it.

**Storage**: files; backups beside the target

**Target Platform**: the operator's machine

**Scale/Scope**: one script, one declaration field, three test groups. No new files except fixtures.

## Design Decisions

**Retention limit: 3, declared.** Enough to recover from a bad projection and the one before it, few
enough that the directory does not grow. Declared in `adapter.yml` so a different operator can choose
differently without editing the script — Principle II.

**Pruning runs AFTER a successful write, never before.** Pruning first would delete the safety net the
write might need. And a pruning failure is swallowed with a warning: FR-003 makes housekeeping
subordinate, because failing a good projection over a stale file the operator never asked about would be
the wrong trade.

**The composition check compares line counts, not content.** A full content comparison would require
holding the source twice and would fail on legitimate trailing-newline differences. The failure being
guarded against is truncation, and a line-count floor catches it. Stated plainly because a reader will
otherwise wonder why the check is not stricter.

**The lint group's third state is the point.** Pass, fail, and SKIPPED — with skipped excluded from the
pass count. A group that reports green because its tool is missing is the `stat -f` defect again: an
assertion that verifies nothing while looking like it did.
